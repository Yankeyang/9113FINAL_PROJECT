# References Folder

Use this folder to store course readings, papers, and notes for the project.

Suggested organization:

```text
docs/references/
├── readings/   # Brightspace weekly readings, lecture PDFs, assigned articles
├── papers/     # Extra academic papers or official reports
└── notes/      # Your own summaries, citation notes, method notes
```

Recommended file naming:

```text
author_year_short-title.pdf
week##_reading-title.pdf
```

Examples:

```text
week05_kde_spatial-analysis.pdf
week07_geoai_modeling.pdf
census_2024_acs_technical-doc.pdf
cec_2026_sb1000_staff-report.pdf
```

After adding files here, the project can use them to support:

- spatial join methodology
- CRS and GIS data cleaning
- KDE hotspot analysis
- benchmark region selection
- spatial modeling and transfer
- policy interpretation
